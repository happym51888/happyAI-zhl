以下课程分别负责“建立全景”“学习框架”和“深入 Agent”，建议按顺序学习。

## 1. Microsoft — Generative AI for Beginners

- [英文课程主页](https://microsoft.github.io/generative-ai-for-beginners/)
- [简体中文版本](https://github.com/microsoft/generative-ai-for-beginners/blob/main/translations/zh-CN/README.md)

免费，包含文字、视频以及 Python/TypeScript 示例，覆盖 LLM、Prompt、Embedding、向量数据库、Function Calling、RAG、Agent 和 LLMOps。

建议优先学习第 1、4、8、11、14、15 和 17 课，用它建立完整概念地图。

## 2. LangChain Academy — Introduction to LangChain

- [Introduction to LangChain: Build AI Agents with Python](https://academy.langchain.com/courses/foundation-introduction-to-langchain-python)

官方免费课程，包含模型、工具、记忆、MCP、状态、多 Agent、Human-in-the-loop 和生产化项目。

建议在理解 LLM、Tool Calling 和 RAG 的基本原理以后学习。

## 3. Hugging Face AI Agents Course

- [AI Agents Course 中文版](https://huggingface.co/learn/agents-course/zh-CN/unit0/introduction)

免费并偏向实战，覆盖 Agent 原理、Think → Act → Observe、smolagents、LangGraph、LlamaIndex、评估和结业挑战。

它适合用来比较不同框架对相同 Agent 概念的实现方式。

## 建议节奏

- 第 1～2 周：Microsoft 精选章节。
- 第 3 周：LangChain Academy。
- 第 4～6 周：Hugging Face Unit 1～2，并完成一个带引用的文档问答 Agent。

学习时把自己的总结持续补充到这个网站，而不是只收藏课程链接。
